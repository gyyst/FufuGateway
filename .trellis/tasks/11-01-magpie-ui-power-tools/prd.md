# 参考 Magpie 优化管理台交互与视觉体验（批次 3：效率与运维）

## Goal

在前两批次（基础体验、可视化洞察）之上，补齐高频操作效率与运维可见性：

1. 全局命令面板（Ctrl/Cmd+K），快速跳转页面与定位实体。
2. Provider 健康弹窗，直接查看断路器、账户与模型失败状态。
3. API Key / 用户预算使用进度，按今日与本月查看预算消耗。

仅改前端静态资源，不新增后端接口。

## Background

- 批次 1 已完成主题、导航、combobox、列表、概览。
- 批次 2 已完成路由诊断可视化、请求执行树、用量图表、客户端接入向导。
- 现有能力：
  - `/admin/health/breakers` 返回 Provider/账户/模型三级断路器状态。
  - `/admin/usage/summary` 支持 `userId`/`apiKeyId` 过滤。
  - 用户与 API Key 含 `dailyBudgetUsd`/`monthlyBudgetUsd`。
  - 配置版本历史已完整（含说明与回滚）；本批次不做版本内容对比（无 payload 接口）。

## Users and Scenarios

### 场景 A：快速跳转

管理员按 Ctrl/Cmd+K，输入「模型」或某个模型名，回车直接进入对应页面并自动填入列表搜索词。

### 场景 B：排查 Provider 异常

管理员在 Provider 列表点击「健康」，看到 Provider 级、账户级、模型级断路器状态与连续失败/窗口失败计数，判断是否需要停用或切换账户。

### 场景 C：预算管控

管理员在 API Key 或用户列表点击「预算」，查看今日/本月已用费用、预算额度与使用百分比，超支时以警示色展示。

## Requirements

### R1. 命令面板

- 快捷键 `Ctrl+K` / `Cmd+K` 打开与关闭，`Esc` 关闭。
- 顶栏提供可点击的「搜索」入口（带快捷键提示），便于发现。
- 搜索范围：页面（14 个）、Provider、模型、别名、Combo、通配符、用户。
- 结果按分组展示，输入即过滤（label/value/描述）。
- 键盘：上下选择、回车执行、Esc 关闭；鼠标点击执行。
- 执行行为：
  - 页面：跳转 `#/<page>`。
  - 实体：跳转对应页面，并把实体名称填入该页列表搜索框。
- 打开时若实体数据未加载，先加载再展示；加载失败不影响页面跳转项。
- 最高显示 50 条结果，避免长列表卡顿。

### R2. Provider 健康

- Provider 列表每行新增「健康」操作。
- 弹窗展示：
  - Provider 级状态、连续失败、窗口失败/总数。
  - 每个账户：名称、状态、连续失败、窗口失败/总数。
  - 每个模型：名称、状态、连续失败、窗口失败/总数。
- 状态含义以文字与颜色共同表达（CLOSED/OPEN/HALF_OPEN 或后端返回值）。
- 接口失败或 Provider 不存在时展示可读提示。

### R3. 预算进度

- API Key 列表每行新增「预算」操作；用户列表每行新增「预算」操作。
- 弹窗展示今日与本月：
  - 已用费用、预算额度、使用百分比、剩余额度。
  - 有进度条；超过 100% 时以危险色显示。
- 未设置预算时明确提示。
- 用量接口失败时展示错误，不影响弹窗其余内容。
- 只读，不修改预算。

## Non-Goals

- 不新增后端接口、不改数据库。
- 不做配置版本内容 diff（无 payload 接口）。
- 不做 CTRL+K 之外的全局快捷键。
- 不做预算告警、邮件通知、自动停用。
- 不做 Provider 卡片视图替换表格。
- 不引入依赖或构建工具。

## Constraints

- 零构建、零依赖；沿用现有 CSS 变量与组件。
- 兼容 CSP（`script-src 'self'`）。
- 所有动态内容经 `esc()` 转义。
- 不破坏批次 1/2 的功能与视觉。
- 中文界面。
